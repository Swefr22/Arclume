# From-Scratch Neural Machine Translation

## Goal

Build a neural machine translation system for:
- Spanish ↔ English
- Tamil ↔ English

## Allowed

- Python
- PyTorch
- NumPy
- pandas
- matplotlib
- publicly available parallel datasets
- GPU/CUDA
- self-developed tokenization
- self-developed neural architecture

## Not Allowed

- Google Translate
- Google Translation API
- Microsoft Translator
- DeepL
- translation APIs
- pretrained translation models
- pretrained embeddings
- Hugging Face pretrained models
- LLM APIs
- existing translation engines

## Principle

All model parameters must be learned from the project's
training data rather than obtained from a pretrained model.
